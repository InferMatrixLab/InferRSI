# InferRSI documentation

Open the entry for the task at hand and follow its links when you need a procedure or evidence.

- **First run or installation.** Start with the [quickstart](quickstart.md). Choose a [Codex](guides/plugins/codex-plugin.md), [DeepSeek Harness](guides/plugins/dsh-plugin.md) or [WorkSwarm](guides/plugins/workswarm-plugin.md) plugin. See [releases](release-notes/) for versions and channels.
- **Run an optimization.** The [operation guide](guides/operations.md) maps commands to Python entry points. Use the [task input guide](guides/task-input.md) to define a workload, the [workflow](guides/optimization-workflow-unification.md) to run it and the [dashboard](dashboard.md) to inspect results. [Task guides](guides/)
- **Choose a benchmark or check a claim.** Start with [engineering benchmarks](benchmarks/engineering-benchmarks.md) or [recorded results](benchmarks/optimization-results.md). For skill changes, follow [local evaluation](guides/skill-evaluation/local-skill-evaluation.md) or the [PR evidence handoff](skill-eval-pr.md#nonpaid-author-handoff). See the [SkillEval guide](guides/skill-evaluation/) for reviewer and operator procedures.
- **Find or contribute knowledge.** Start with [Find and Collect](knowledge-operations.md) or the [contribution guide](guides/knowledge/knowledge-contribution-workflow.md). The [Knowledge module](../src/inferrsi/knowledge/README.md) links to the library and its contracts.
- **Change the repository.** Read the [contributor guide](contributing.md) and [collaboration rules](agent-collaboration.md). [Architecture](architecture.md) records shared boundaries, and [module layout](guides/module-layout.md#module-documentation) links to the four module guides. [Versioned contracts](contracts/) and the [engine template](template/) support implementation.
- **Trace a result.** [Field notes](field-notes/) describe specific workloads, including
  [DeepSeek V4.1 Flash on Ascend](field-notes/deepseek-v41-flash-service-reuse.md).
  [Source audits](reviews/) and [campaign evidence](../evidence/) retain their scope and provenance.
  Check the [privacy and security guide](privacy-security.md) before sharing artifacts.
