# Bounded KV edit/check integration — model-free

This slice connects the fixed edit protocol to the synthetic CPU task. It is not
a general coding agent, paid launcher, production KV implementation or efficacy
result. A2/A3 remain one prospective exploratory paired block, not a completed
model experiment.

## Implemented boundaries

- `kv_edit_workbench.VisibleWorkbench` accepts a frozen, extracted DEVELOPMENT
  suite and public benchmark inputs/expected data. The full verifier collection,
  optimized control and hidden grader inputs are not supplied to the worker.
- Candidate code runs only through `kv_reclamation.invoke` and its existing
  network-free bubblewrap boundary. The visible benchmark composes the existing
  `run_experiment`/`evaluate` AB/BA path with content-addressed source snapshots.
  Host-observed whole-command elapsed time includes sandbox/interpreter startup;
  full output must match trusted expected data before a metric is accepted.
- Every revision is retained outside the exposed workspace. Final hidden grading
  takes the immutable returned source bytes and their exact digest, never a later
  reopening of the mutable actor path. Its results do not feed another edit.
- `tools.kv_edit_pilot.prepare_scripted` freezes explicit actor files, prompt,
  public suite, baseline, scripted responses and trusted dependency hashes.
  `run_supervised` launches the exact fixed worker with `-I` through existing
  `execute_command`, under the same inherited absolute deadline used by every
  tool. A blocked worker is terminated, not granted a fresh callback deadline.
- `tools.kv_worker_supervisor.supervise` owns the shared private grant/completion
  bridge. The scripted wrapper supplies only a fixed secret-free worker command
  and environment. An injected live transport is not part of this slice.
- Existing `authorization_broker` is reused. Bounded private files outside the
  actor workspace relay only the exact request grant and raw four-class usage.
  The trusted parent reconciles completion before another grant. Missing, late,
  invalid or unknown usage does not free capacity or permit another arm.
- An optional injected admission session exercises existing durable PR/day
  claims and their live checks. The actual session and GitHub authority remain
  in the parent; the worker receives only an ephemeral loopback gate capability.
  See [pilot admission](kv-pilot-admission.md).

The worker has **no provider transport, provider credential option, account
configuration or live-execution mode**. Its response file is JSON data, not an
executable script. Every result identifies zero real model calls and zero new
provider charges. Candidate source is never imported on the host.

## Qualification and limits

`tests/test_kv_edit_workbench.py` exercises edit/check/ABBA/rewrite/submission and
separate hidden grading with scripted sandbox outputs. `tests/test_kv_edit_pilot.py`
exercises the private request/usage bridge against fake durable stores, real
loopback authorization, missing usage, expired admission day, source/prompt drift
and a real hard timeout of a trusted blocking worker fixture. Scripted sandbox
outputs are **not** evidence that bubblewrap isolation worked.

A real worker always probes isolation before its first simulated request. An
unavailable namespace or missing trusted boundary yields `INCONCLUSIVE`, without
host execution, a weaker sandbox, a different agent or a new paid attempt.
Qualified-host results must bind the exact implementation/plan/source hashes.
Artifact replay qualification alone does not certify the entire actor path or
arbitrary descendant cleanup.

The actor/tool worker is trusted controller code, not an OS-sandboxed coding
agent. It interprets bounded response JSON as fixed tools. A2/A3 model-visible
files are constrained by the exact exposure manifest and read allowlist;
generated candidate execution alone is isolated by fresh workdirs, restricted
runtime mounts and unchanged candidate resource limits.

`tools.qualify_kv_edit_actor` adds a separate, zero-provider software-control
receipt to the existing Ready Ubuntu 22.04 job. It requires all of:

- Complete pinned K-owner exposure only in scripted A3, identical fixed tools,
  two edit/check/measurement revisions, independent readback of retained source
  bytes and receipts for revisions 0–2, and immutable final hidden grading.
- `tools.kv_edit_inputs` constructs identical common task/contract/starter,
  workbench/development files and prompt for both arms; only A3 adds K. Public
  development bytes contain IDs/events, not expected outputs or grader traces.
  A per-arm common-contract digest binds exact files, protocol/client, limits,
  check IDs, metric, suite and baseline independently of scripted responses.
- Production-profile denial of actual package/K/oracle/reference paths and
  synthetic canaries. Runtime enumeration resolves bind roots but never follows
  escaped descendant aliases; bounded size-indexed hashes detect renamed copies
  including the complete hidden corpus. Escaped aliases must be unreadable in
  the unchanged production sandbox; missing visibility is INCONCLUSIVE.
- A surviving observer around the actual outer-executor → trusted worker →
  nested executor → sandbox chain. An authored fork/setsid probe binds its
  namespace PID, starttime and PID-namespace identity to an already-owned host
  descendant. Normal exit, outer-worker hard timeout and cancellation require
  this observed chain and zero live survivors. Recovery kills never convert a
  failed cleanup into PASS. Candidate execution still forbids fork.

The separate `kv-actor-qualification-<run>-<attempt>` artifact binds the exact
clean revision, dependency closure, plan, exposure, per-arm receipts and raw
archive digest. Prior task-only qualification is not this actor qualification.
Scripted actor identities include scripted responses; they do not identify a
future live actor or establish exact live exposure/transport qualification.
The final submitted tree still needs its actual hosted result; local fake
fixtures, inventory-only checks and green repository tests cannot substitute.
