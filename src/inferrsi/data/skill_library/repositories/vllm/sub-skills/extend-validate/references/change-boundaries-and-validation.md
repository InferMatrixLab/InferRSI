# Change boundaries and validation

## Choose the owner

| Requested behavior | Start here | Required checks before claiming success |
|---|---|---|
| Fairness, token budget or admission | `vllm/v1/core/sched/`, `config/scheduler.py`, `engine/arg_utils.py` | Budget and active-sequence bounds, progress, preemption, long/mixed prompts, aborts, async placeholders and speculative slots |
| Prefix identity, reuse or eviction | `vllm/v1/core/kv_cache_manager.py`, `block_pool.py`, `kv_cache_utils.py`, coordinator/group managers | No invalid hit, LoRA/MM/salt separation, shared references, writable tails, partial/hybrid groups and reset/invalidation |
| KV transport | `distributed/kv_transfer/kv_connector/v1/base.py` and selected connector | Metadata corresponds to allocated blocks; load before use; save before free; async completion, abort, partial failure and explicit fail/recompute |
| Attention/backend | `vllm/v1/attention/selector.py`, platform selector, selected backend/kernel | Supported dtype/head/block/layout, masked/variable lengths, prefill/decode, graph capture, distributed and numerical reference comparisons |
| Quantization | `model_executor/layers/quantization/` and model weight loading | Format/checkpoint dispatch, scales/layout, device support, per-layer and end-to-end quality, TP/EP weight placement |
| Compilation/fusion | `vllm/compilation/`, `config/compilation.py`, affected model/op | Graph boundaries/hash factors, dynamic shapes, eager equivalence, capture/replay, cache invalidation, actual kernel dispatch |

These directories locate likely owners; inspect the target model/runner revision before editing. Some model-specific paths are in `vllm/models/` in this snapshot, so older model_executor-only maps are incomplete. A registered quantization class or custom proposer is a hook, not a validation result. Scheduler configuration warns that custom interfaces are not public and compatibility may change. ## Correctness gates

1. Scheduling: scheduled tokens must fit their budget, input budget must include drafts, and RUNNING admission must remain bounded. Test a request whose prompt/output reaches the context boundary and a preempted request with in-flight output. [invariants](https://github.com/vllm-project/vllm/blob/2521446ac8c92937b5a32b7dc2a84ef7fa8e99c5/vllm/v1/core/sched/scheduler.py#L1403-L1415) [async_tests](https://github.com/vllm-project/vllm/blob/2521446ac8c92937b5a32b7dc2a84ef7fa8e99c5/tests/v1/core/test_async_scheduler.py#L539-L601)
2. KV: no consumer reads unfinished transfer or freed blocks; cache hits represent identical computation; different semantic identities do not share incorrectly. Test cold/warm, zero/new hits, pressure/eviction, cancellation and hybrid groups relevant to the change. [kv_lifetime](https://github.com/vllm-project/vllm/blob/2521446ac8c92937b5a32b7dc2a84ef7fa8e99c5/vllm/v1/core/block_pool.py#L666-L795) [connector_finish](https://github.com/vllm-project/vllm/blob/2521446ac8c92937b5a32b7dc2a84ef7fa8e99c5/vllm/distributed/kv_transfer/kv_connector/v1/base.py#L371-L408)
3. Speculation: preserve accepted/recovered/bonus semantics, termination and rollback. Greedy equality alone does not validate stochastic correctness. Use target-distribution tests and seed behavior under the supported sampling configuration. Synthetic acceptance is excluded from output correctness. [rejection](https://github.com/vllm-project/vllm/blob/2521446ac8c92937b5a32b7dc2a84ef7fa8e99c5/vllm/v1/sample/rejection_sampler.py#L46-L71) [rejection_tests](https://github.com/vllm-project/vllm/blob/2521446ac8c92937b5a32b7dc2a84ef7fa8e99c5/tests/v1/sample/test_rejection_sampler.py#L380-L416) [synthetic](https://github.com/vllm-project/vllm/blob/2521446ac8c92937b5a32b7dc2a84ef7fa8e99c5/vllm/config/speculative.py#L529-L549)
4. Kernel/quantization: establish tolerances per dtype/operation and task quality. Do not require universal bit equality across kernels, nor allow arbitrary drift. Test shapes that cross block, capture and partition boundaries.
5. Parallel/transfer: validate rank/weight mapping, collective ordering, layout and abort/failure recovery under the actual topology. A single-device result cannot certify multi-node behavior. [context_parallel](https://github.com/vllm-project/vllm/blob/2521446ac8c92937b5a32b7dc2a84ef7fa8e99c5/vllm/config/parallel.py#L591-L629) [world_size](https://github.com/vllm-project/vllm/blob/2521446ac8c92937b5a32b7dc2a84ef7fa8e99c5/vllm/config/parallel.py#L946-L965)

## Native test candidates, not tests claimed passed

```bash
python -m pytest tests/v1/core/test_scheduler.py -q -k 'max_num_active_seqs_caps_admission or schedule_partial_requests'
python -m pytest tests/v1/core/test_async_scheduler.py -q -k 'kv_pressure_preemption_with_inflight_output or abort'
python -m pytest tests/v1/sample/test_rejection_sampler.py -q -k 'rejection_sampling_approximates_target_distribution or deterministic_when_seeded'
```

The named test functions were found in the pinned source. Use the repository's actual dependencies and suitable accelerator; collection itself imports heavyweight repository conftest. Do not apply `--noconftest` to these engine tests to manufacture a pass. Prefix/cache tests live in `tests/v1/core/test_prefix_caching.py` and `test_single_type_kv_cache_manager.py`; select cases relevant to the actual groups. Connector correctness has unit tests under `tests/v1/kv_connector/unit/` and NIXL integration under `tests/v1/kv_connector/nixl_integration/`. Distributed, compilation and quantization changes require the matching test directories and backend matrix. [scheduler_tests](https://github.com/vllm-project/vllm/blob/2521446ac8c92937b5a32b7dc2a84ef7fa8e99c5/tests/v1/core/test_scheduler.py#L211-L281) [async_tests](https://github.com/vllm-project/vllm/blob/2521446ac8c92937b5a32b7dc2a84ef7fa8e99c5/tests/v1/core/test_async_scheduler.py#L539-L601) [test_deps](https://github.com/vllm-project/vllm/blob/2521446ac8c92937b5a32b7dc2a84ef7fa8e99c5/tests/conftest.py#L28-L48)

One metadata-only native candidate, `tests/test_zentorch_version_pin.py`, compares zentorch and CPU torch requirement strings and does not need model execution. The Creator attempted it with `--noconftest`; missing `regex` blocked collection. This does not validate the inference engine. No dependency shims were used and no setup.py was executed. [native](https://github.com/vllm-project/vllm/blob/2521446ac8c92937b5a32b7dc2a84ef7fa8e99c5/tests/test_zentorch_version_pin.py#L1-L77)

## Review and remote handoff

Provide the behavioral diff, pinned source/test names, actual commands and results, unsupported combinations, and pending device checks. Review config propagation and graph hash changes, output/abort ordering, shared KV references and release timing. A performance claim requires a valid baseline, equal work and quality, repeated measurements and the load region where the claim holds. If native checks cannot run locally, complete feasible static review and provide remote commands without claiming a fix is proven.
