## Portable workflow adaptation, not an import receipt

The adopted sequence is repository/source/test discovery, selected depth and
exclusion planning, backend classification, independent bounded-resource
construction, whole-owner reconciliation, assertion-backed usability checks,
static/package access checks and review. One root procedure routes three deep
references; these are one boundary-audit workflow, not a mirror of every app
folder or a claimed complete model-conversion/deployment guide.

Local Dream is Kotlin/C++ Android software, not a Python distribution. No
fictional pip package, import smoke or CPU-equivalent device run is supplied.
The only Python code in this owner is an original standard-library declaration
screen. Required ARM64 Android/MNN/QNN/Hexagon/model evidence is unavailable and
remains `BLOCKED_REQUIRED_BACKEND / not_run`. InferRSI installation verifies
knowledge-resource access, not Local Dream execution. There was no DisCo CLI,
managed router/import transaction or fully verified/import-ready declaration.
Source hyperlinks are attribution/evidence, not instructions that require the
source checkout at use time. All operating guidance and helper bytes are local.

| Surface | Selected depth | Remaining boundary |
| --- | --- | --- |
| Android process/remote lifecycle | Desired/serving, grace/reconcile, startup-only inputs, health differences, stale errors and unauthenticated host control | All OS interleavings, UI flows, network/security certification and live endpoints |
| Native dispatch/lifetimes | Selected MNN/QNN/Anima/DiT routing, shared lock, callback cancellation, selected low-RAM/context replacement | Complete kernels/schedulers/ownership, numerical parity, driver behavior and physical memory fit |

| Packaging/ABI | Core executable versus DiT library/DSP skels, selected C API and SDK/githash boundaries | Resolved dependencies/patch semantics, actual build/package symbols, load or dispatch |
| Tests/scripts | Two host-test definitions and selected build/staging script ownership | Upstream tests were not run; build scripts are reference-only because they patch/build/stage native SDK artifacts |
| Other app capabilities | Named as exclusions only | Import/download/migration/storage implementation, full UI/history/backups, all model assets, external guide site and six unrelated discovered repositories |

Whole-file identity does not mean exhaustive analysis. A source assertion or
comment is labelled as such; a proposed native discriminator is not an execution
receipt. No measured Accelerator/RAM/SSD/Network/OS gain is added by this owner.
