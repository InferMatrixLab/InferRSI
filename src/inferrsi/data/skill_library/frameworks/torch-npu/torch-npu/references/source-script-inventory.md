# Source script decisions

Every discovered source workflow/helper in the selected script roots is listed
below. `reference-only` preserves a development workflow, not an instruction to
run an unbundled source file. The source checkout is not required to run this
skill's three helpers. No complete source build/CI/test runner was copied.

- `copy`: none; exact license notices are retained separately.
- `adapt`: broad environment collection becomes sanitized package/device probing.
- `wrap`: small public-API examples become explicit opt-in cases.
- `reference-only`: compiled/build/codegen/source-bound examples, with reasons.
- `exclude`: unrelated maintainer CI/release/reporting side effects.

The original stdlib helper `operator_contract.py` checks planning declarations;
it is new glue grounded in the inspected registration/generation contracts,
not a replacement schema parser or code generator. See [operator development](../sub-skills/operator-development/SKILL.md).
