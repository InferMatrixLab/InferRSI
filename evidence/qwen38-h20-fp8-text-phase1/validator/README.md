# Validator preparation

Freeze the example validator, profile helpers, trial adapters and offline kernel
binding with their SHA-256 hashes before execution. Numerical gates belong to
acceptance #57 and its frozen runtime records; this directory supplies no defaults.
Missing model, precision, kernel or source evidence is INCONCLUSIVE. Complete
numerical rejection is FAIL. Neither outcome may be relabelled as performance.

Freeze the additional service validator, request fixtures and lifecycle protocol
separately. Require exact deterministic serial/HTTP/SSE/concurrent token and text
agreement, ordered terminal framing, actual overlapping request ownership,
isolated cancellation and evidence of state/capacity release and subsequent reuse.
An unobserved cancellation or overlap cannot pass because a request completed
early. Missing observations, identity or cleanup evidence are INCONCLUSIVE;
complete evidence of a protocol or isolation violation is FAIL. CPU fake-engine
results cannot qualify the real FP8 model service. Service equivalence does not
replace the independent reference-based numerical validation.
