# W3/W4 exact distribution extension

Independent CPU script/results; old oracles, engine and gates unchanged. W3 means two drafts plus bonus; W4 means three drafts plus bonus. Tests enumerate all draft sequences and all acceptance/rejection branches using Fraction. Proposal distributions may ignore intermediate drafts; target distributions explicitly depend on the already accepted history. After first rejection, correction uses normalized positive part(p-q), all remaining pre-generated drafts are discarded, and ordinary target continuation completes the fixed-length comparison sequence. All-accepted paths sample target bonus. Tail remaining1/2/3 uses at most remaining-1 drafts and a bonus, with remaining1 sampling target directly.

At each accepted-prefix node, accepted mass min(p,q) plus correction mass(p-q)+ equals p. Impossible q=0 draws are omitted before division; q=0<p is recovered through correction. Rejection normalization occurs only when rejection has positive probability. If p=q, including zero supports, all drafts accept and no 0/0 occurs. Summing probabilities of unused draft suffixes yields1, so discarding them after rejection preserves target continuation. By conditional induction this gives the exact joint target law; repeated rounds compose the same local argument. Finite tests are implementation evidence, not a proof of a floating-point implementation.

802 cases passed:640 fixed-proposal/history-dependent-target cases,160 conditional p=q cases,2 explicit disjoint-support cases. Fixed-proposal tail subsets:128 remaining1,128 remaining2,64 remaining3 (W4 only). Vocabulary2, target/proposal families include deterministic disjoint supports, full-overlap uniform and partial-overlap nonuniform probabilities. All outputs equal independently enumerated autoregressive target joint distributions; explicit disjoint support commits one correction, p=q commits min(window,total).

No random sampling, GPU, native filtering, head-position/model verification, finite-precision guarantee or performance claim. Original result files are not overwritten; importing and calling check() reruns without writing.
