# Campaign template

1. Choose a `campaign_id` (e.g. `my-model/cpu×1`).  
2. Create `evidence/<campaign_id>/` with `plan/`, `results/`, `patch/`, `validator/`.  
3. Open an acceptance issue listing **pinned baseline SHA** and **pinned candidate SHA**.  
4. Record verdict `PASS`, `FAIL`, or `INCONCLUSIVE` with links into `results/`.  

Do not commit live campaign SHAs into this template folder.
